# 検証済み設定例と検証範囲

## 集英社・三段枠の設定例

この設定は特定の制作条件での検証例であり、全利用者の必須設定ではない。ユーザーがこの設定を選んだ場合に適用する。

- プリセット：集英社マンガ誌汎用（少年誌・少女誌・青年誌共通/新書・B6判単行本化）
- 右綴じ・左開始・「対するページを見開きにする」。例：6ページなら1 / 2–3 / 4–5 / 6。
- テンプレート：「3段等分」。各物理ページに横長3コマ、見開きには左右合計6コマ。
- 検証機ではプリセットとテンプレートが利用可能だった。他の環境にインストール済みとは仮定しない。

照合用の観測値：単ページ257×364mm、600dpi、モノクロ、基本線数60。仕上がり221.81×328.78mm、裁ち落とし7mm、基本枠180×270mm、オフセット0。セーフライン天/地17.49mm、ノド20.90mm、小口17.23mm。公式仕様の代替ではなく、プリセット選択結果の記録。

参考：[CSP公式の原稿設定](https://tips.clip-studio.com/ja-jp/articles/1375)、[マンガMee編集部の説明](https://note.com/mangamee/n/n46fdfce113a4)。

## 実機検証の範囲

環境：macOS、CLIP STUDIO PAINT EX 5.1.4、Computer Use。2026-09-21〜22実施。

- 4ページ・9項目：旧ストーリーエディター方式で入力・保存。再出力本文の完全一致と4ページ画像を確認。ただし1項目1レイヤー方式の検証ではない。
- 6ページ・5セクション・6項目：CosenseのUserScriptからmanifestを書き出し、1 / 2–3 / 4–5 / 6の作品を作成。各物理ページの三段枠、6個の独立文字レイヤー、コマ枠外のテキストフォルダ、保存をGUIで確認。書き出しダイアログの問題で本文の再出力照合は未完了。
- 種別別の書体、自動吹き出し図形、大量ページ、無人の通し実行、記録からの自動再開は未検証。

個人のCosense URL、ユーザー名、ローカル保存先、検証原稿は配布物に含めない。実行時に指定する作品名・保存先・書体設定とは分離する。
